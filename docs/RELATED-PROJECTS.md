# Related projects / 相关项目

NewsBridge is based on [Zara Zhang's reading-block-lark](https://github.com/zarazhangrui/reading-block-lark/tree/main), with the original MIT license retained. Its reading workflow now uses Bitable and daily unread reminders in Feishu.

NewsBridge 基于 [Zara Zhang 的 reading-block-lark](https://github.com/zarazhangrui/reading-block-lark/tree/main) 修改，保留原 MIT 许可证，阅读流程改为多维表格管理与每日未读提醒。

Zara also publishes [lark-coding-agent-bridge](https://github.com/zarazhangrui/lark-coding-agent-bridge/tree/main), an independent project connecting Feishu conversations to coding tools. Consult that project's own documentation if you want to use it separately.

Zara 的另一个开源项目 [lark-coding-agent-bridge](https://github.com/zarazhangrui/lark-coding-agent-bridge/tree/main) 用于把飞书会话连接到编程工具。如需单独使用，请参考该项目自身的说明。

NewsBridge does not install, configure, or call this bridge. Its configured destination is simply a Feishu conversation; delivery does not imply that any external tool has processed the content.

NewsBridge 不安装、配置或调用该桥接项目。发送目标是普通飞书会话，送达不代表其他工具已处理内容。
