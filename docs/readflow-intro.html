03

资料有归处，分工也清楚。

数据库是唯一主库

自建 ReadFlow 服务以 SQLite 保存素材和已确认的回顾。Chrome 保留本机待同步内容；断网收藏不冒充备份成功。

AI 留在你熟悉的地方

默认使用你已经配置好的 LLM agent。飞书可以是与它对话的入口，也可以使用其他已接入 agent 的对话工具。真正执行分析的是 agent；ReadFlow 不直接调用模型 API，也不保存模型密钥。

保留，也可以带走

主动导出 CSV，包含标题、链接、状态、收藏时间、标签、笔记和标记已读时间。完整备份仍需保存服务端状态目录。

04

先收藏，再连接。

你可以先体验本机收藏。需要跨设备资料库或 agent 回顾时，再配置自己的服务。

获取项目源码 ↗查看配置指南 ↗

Chrome 106+。自建参考服务需要 Node.js 22.13+ 与已有 HTTPS 地址。无需指定云平台。

  1. 解压插件到固定文件夹

    在 GitHub 选择 Code → Download ZIP，下载后先解压。找到包含 manifest.json 的 ReadFlow 文件夹，保留在固定位置；不能直接加载 ZIP 压缩包。

  2. 开启开发者模式，加载插件

    在 Chrome 地址栏输入 chrome://extensions 并回车。打开右上角的“开发者模式”，点击“加载已解压的扩展程序”，选择上一步包含 manifest.json 的文件夹。看到 ReadFlow 扩展卡片即表示安装成功。

    升级时保持安装目录不变。移动文件夹可能改变扩展 ID，需重新更新服务端白名单。

  3. 打开网页，收藏当前页

    在 Chrome 工具栏点击拼图形状的“扩展程序”，将 ReadFlow 固定到工具栏。打开要保存的文章或视频页面，点击 ReadFlow 图标，选择“收藏当前页”，按需填写标签和笔记，保存后查看成功或失败提示。进入收藏列表可切换未读、已读与跳过。

  4. 按指纹确认连接

    将设置页的“复制配置任务”内容粘贴到你已有的 agent 对话中；飞书只是可选入口，不必为 ReadFlow 更换对话工具。取得 HTTPS 服务地址后，在 Step 2 获取指纹并复制确认任务；服务端批准后，点击 Step 3 完成连接。

  5. 授权已有 agent 回顾

    按 agent 接入指南独立配对。之后在原有对话中请求回顾；确认具体内容后再保存，不需要在插件填写模型密钥。

05

开始之前，你可能想知道。

必须使用飞书或在线表格吗？

不需要。这里的飞书是已有 LLM agent 的一种可选对话入口，并不负责运行模型或保存主库；你也可以在其他已配置好 agent 的对话工具中使用。分析和带引用的回顾由获授权的 agent 完成，确认后的结果保存到 ReadFlow 数据库。当前不提供飞书多维表格或 Google 表格同步。

能自动读取文章全文或转写视频吗？

当前保存标题、链接、标签和个人笔记，不抓取正文、不下载或转写视频。agent 只有标题和链接时，应说明信息不足，不能假装已经读过全文。

分析结果在哪里？谁负责确认保存？

回顾首先显示在已有 agent 对话中。agent 展示最终摘要和引用，收到你的明确确认后，通过授权接口保存；之后可以通过 agent 按回顾 ID 查询。ReadFlow 校验引用与内容摘要，但无法独立核实外部聊天中的确认者身份，因此只应授权你信任的 agent。Chrome 内的独立回顾列表尚未提供。

会每天自动推送阅读提醒吗？

每日阅读提醒已暂时移除，定时 AI 回顾也尚未提供。当前以用户主动发起讨论为主；未来的主动推送需要单独配置和明确授权。

先在本机收藏，会不会自动备份？

不会。本机模式只把资料保存在当前浏览器。连接服务并同步成功后才进入数据库；卸载扩展或清理浏览器数据可能丢失未同步内容。服务端也需要由配置者定期备份。
