    Using the reference connection yourself?

    Run this command in the project folder on the machine running your connection, after preparing private/host.json:

    node examples/run.mjs init private/host.json

    Open access.key in your configured stateDir and paste its contents here. The example configuration uses private/state/access.key. Initialization preserves an existing key.

    Use the connection key here, not a provider App Secret, JSON private key or access token. Leave blank to keep a saved key. To rotate it, replace the host key, then enter and save the new key here. Reinstallation or another Chrome profile may require entering it again.
