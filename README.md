# ReadFlow

[English](README.en.md) · [项目介绍页](https://bot.fifteenbao.com/readflow/)

**使用前请注意：请在你自有、已配置好的 LLM agent 环境中使用 ReadFlow。本项目不提供服务器或托管服务，也不提供 agent 或模型账号；需要你自行准备 ReadFlow 服务的运行环境并完成授权接入。**

收藏值得理解的文章和视频，再与自己的 agent 回顾。Chrome 是收藏入口；自行运行的 ReadFlow 服务通过 SQLite 保存资料库；飞书只是已有 agent 的可选对话入口，也可以使用其他已接入 agent 的对话工具。**数据库是唯一主库。** 已有 agent 可通过独立配对查询收藏、生成带引用的回顾，并在用户确认后保存到 ReadFlow，见 [Hermes 接入指南](docs/AGENT.md)。

## 这个插件用来做什么

ReadFlow 帮你保存需要花时间理解的文章和视频链接，记录标签、笔记及阅读状态，再把这些素材交给自己已有的 agent 做带引用的回顾。你可以讨论“那年今日”、阅读习惯或可能忽略的证据；确认具体摘要后，agent 才将回顾保存到 ReadFlow。它不是全文抓取器，也不替你部署或提供 AI 助手。

## 使用前准备

- **Chrome 106+ 和插件文件夹**：下载后解压到固定目录，按下方步骤加载。
- **你自己的已配置 agent**：能执行本项目签名工具或相同 HTTP 协议；参考工具需要 Node.js 22.13+。飞书只是可选对话入口，不必为 ReadFlow 新建飞书机器人。
- **自行准备的服务运行环境**：完整同步与回顾功能需要单机 POSIX 环境、Node.js 22.13+、可持久保存 SQLite 的私有目录和已有 HTTPS 地址。项目提供参考服务源码，**不提供服务器或托管服务**。
- **一次连接授权**：安装后取得真实扩展 ID，交给服务配置者加入白名单；核对配对指纹后批准。agent 使用自己的独立配对身份，不复制 Chrome 私钥。无需向插件填写模型密钥或表格链接。

只想先体验收藏，可选择“先在本机收藏”；不需要先运行服务，但本机内容不是数据库备份，也不能直接用于 agent 查询。完整配置见 [SETUP](SETUP.md)。

## 各部分的职责

| 部分 | 职责 |
| --- | --- |
| Chrome | 标题／链接、选填标签和笔记、本机待同步队列、按状态筛选的收藏列表和状态操作 |
| 自行运行的 ReadFlow 服务 | SQLite 数据库、身份校验、去重、同步、回顾保存与 CSV 导出；项目仅提供源码，不提供服务器 |
| 飞书等对话工具（可选） | 作为已有 agent 的对话入口，展示分析、承载追问和保存确认；真正执行分析的是 agent |
| 已有对话型 agent（不限平台） | 可协助配置，通过授权接口查询收藏、分析与追问，确认后保存回顾；模型与凭证由其环境管理 |

## 安装 Chrome 插件

需要 Chrome 106 或以上版本。

1. 下载 Releases 中的插件安装包（如已发布），或在本仓库选择 **Code → Download ZIP**。
2. **先解压到固定文件夹**，找到直接包含 `manifest.json`、`src/` 和 `icons/` 的文件夹；不能直接加载 ZIP 压缩包。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并回车，打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择上一步的文件夹。看到 ReadFlow 扩展卡片即表示安装成功。
5. 点击 Chrome 工具栏拼图形状的 **扩展程序**，将 ReadFlow 固定到工具栏。打开文章或视频页面，点击 ReadFlow 图标，选择 **收藏当前页**，按需填写标签和笔记，保存后查看成功或失败提示。

也可使用 Node.js 22.13+ 从源码打包：

```sh
npm run build
```

生成 `dist/readflow/`、`dist/readflow.zip` 和 `dist/readflow-V0.4.3.zip`，无需安装 npm 依赖。更新时覆盖**原安装目录**，再在 Chrome 中重新加载。移动目录可能导致扩展 ID 改变，需要同步更新服务端白名单；卸载可能清除本地收藏。

## 第一次使用

首次弹窗提供设置指引，也可明确选择 **先在本机收藏**。本机模式不等于数据库备份。已配置后，服务暂时离线也可收藏，内容保存在本机待同步队列；收藏时尝试同步，并明确显示是否获得数据库确认。

设置页只需填写 **ReadFlow HTTPS 服务地址**，保留应用子路径。这不是飞书表格链接。在 **Step 2** 点击“连接服务器，获取指纹”，再点击“复制确认任务”发给配置服务器的 agent。agent 核对完整指纹并批准后，在 **Step 3** 点击“已获批准，完成连接”；插件验证授权并保存。配置者须将设置页显示的 Chrome 扩展 ID 填入服务端白名单。Chrome 仅申请该主机的访问权限；扩展 ID 本身不是认证，后续请求需要签名。

完成配置后首次引导自动隐藏，临时离线不会要求重新配置。高级设置中的“立即更新”用于上传待同步收藏并获取最新资料与阅读状态，不会导出到飞书。“断开当前资料库”仅用于更换连接：本机列表归档、服务端内容保留，不撤销配对；操作前会再次确认。

设置页提供可复制给自己 agent 的任务，同时把项目目录交给它。插件不会自动发消息。详见 [SETUP](SETUP.md) 和 [Agent 配置说明](SETUP.md#交给-agent-配置)。

## 收藏与阅读

打开 HTTP(S) 文章或视频，点击 ReadFlow，选填标签与笔记后收藏。只保存标题和链接，不抓取正文、不下载视频、不转写。同步成功的记录存入数据库。收藏页是默认首页，未读／已读／跳过三个筛选均显示数量。每行展示标题、来源、时间、标签和可展开笔记，可直接切换阅读状态；消息送达不代表已读，已关联条目的状态变更须成功写入服务后才确认。

另外，项目保留可单独配置的飞书私聊链接收录功能，与 Chrome 共用数据库并按链接去重。这与使用飞书作为 agent 对话入口是两项独立能力。处理任务落库后，机器人确认新增／已存在的数量；不抓链接正文，也不开始 AI 对话。[飞书配置](docs/FEISHU-INBOX.md)。

## 按需导出

设置 → **导出资料库**：

- **下载 CSV**：先上传待同步收藏，再下载数据库中的全部记录，包含 UTF-8 编码和表格公式注入防护。服务错误会中止导出。无需飞书凭证；CSV 包含素材与笔记，但不是完整数据库备份。


## 标签与阅读状态

弹框只展示少量已选标签或搜索结果，不铺开全部标签。输入标签名搜索，勾选已有标签或点击“添加”／按回车新增；选中数量不限，每个标签最多 50 字。未展示的已选标签仍会保存。收藏列表不依赖动画显示文字，支持系统减少动态效果设置。

每日阅读提醒暂时移除，待未来扩展；升级服务后即使旧配置仍启用也不会发送。请停用已有的 `daily` 调度，飞书链接收录继续使用 `ingest`。

## 部署与边界

[自建指南](docs/SELF-HOSTING.md) · [架构](docs/ARCHITECTURE.md) · [接口约定](docs/CONNECTION.md) · [安全](SECURITY.md)

参考服务使用单机私有 SQLite 文件，不限定云平台、CLI 或 agent。备份时停止服务并备份整个私有状态目录。统一删除、Chrome 回顾列表、定时 AI 回顾、多机数据库集群尚未实现。Hermes 真实环境接入仍需验证。飞书测试使用模拟响应，真实部署仍需验证权限和回调。

当前仅维护标题、链接、阅读状态、收藏时间、标签、笔记、标记已读时间七项；不生成正文、分类或评分。笔记与原备注合并为一个输入，已有不同文字合并保留；数据库中已有的其他内容保留，但不再作为默认导出列。

## 对话型 agent 与消息渠道

默认用户已配置好自己的 LLM agent；飞书只是其可选对话入口，也可使用其他已接入该 agent 的对话工具。AI 阅读讨论不限定消息平台；分析由用户已有的对话型 agent 完成。ReadFlow 不直接调用模型 API，不要求模型密钥，也不再同步多维表格。当前提供独立配对的 agent 查询、引用校验、确认后保存及回顾查询接口。Hermes 可通过 [接入指南](docs/AGENT.md) 中的签名工具完成配置；用户在已有对话中发起回顾并确认保存，不自动转发收藏或启动分析。真实 Hermes 环境仍需联调，Chrome 回顾列表与定时 AI 回顾尚未实现。消息送达不代表分析已执行。
