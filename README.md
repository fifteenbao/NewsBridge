# ReadFlow

收藏值得理解的文章和视频，再主动唤起阅读。Chrome 是收藏入口；ReadFlow 服务通过 SQLite 保存资料库；飞书可选，用于收链接和发送阅读邀请。**数据库是唯一主库。** 已有 agent 可通过独立配对查询收藏、生成带引用的回顾，并在用户确认后保存到 ReadFlow，见 [Hermes 接入指南](docs/AGENT.md)。

## 各部分的职责

| 部分 | 职责 |
| --- | --- |
| Chrome | 标题／链接、选填标签和笔记、本机待同步队列、按状态筛选的收藏列表和状态操作 |
| ReadFlow 服务 | 数据库、身份校验、去重、同步、持久化发送记录和定时任务入口 |
| 飞书机器人（可选） | 私聊链接收录、落库后的确认、每日阅读卡片 |
| 已有对话型 agent（不限平台） | 可协助配置，通过授权接口查询收藏、分析与追问，确认后保存回顾；模型与凭证由其环境管理 |

## 安装 Chrome 插件

需要 Chrome 106 或以上版本。下载 Releases 中的安装包（如已发布），或本仓库 **Code → Download ZIP** 源码。解压到固定目录，打开 `chrome://extensions`，开启 **开发者模式**，点击 **加载已解压的扩展程序**，选择直接包含 `manifest.json`、`src/` 和 `icons/` 的文件夹。通过 Chrome 的扩展程序菜单固定 ReadFlow。

也可使用 Node.js 22.13+ 从源码打包：

```sh
npm run build
```

生成 `dist/readflow/`、`dist/readflow.zip` 和 `dist/readflow-V0.4.1.zip`，无需安装 npm 依赖。更新时覆盖**原安装目录**，再在 Chrome 中重新加载。移动目录可能导致扩展 ID 改变，需要同步更新服务端白名单；卸载可能清除本地收藏。

## 第一次使用

首次弹窗提供设置指引，也可明确选择 **先在本机收藏**。本机模式不等于数据库备份。已配置后，服务暂时离线也可收藏，内容保存在本机待同步队列；收藏时尝试同步，并明确显示是否获得数据库确认。

设置页只需填写 **ReadFlow HTTPS 服务地址**，保留应用子路径。这不是飞书表格链接。点击 **配对并检查**，在服务端核对页面指纹后批准，再次检查并 **保存设置**。配置者须将设置页显示的 Chrome 扩展 ID 填入服务端白名单。Chrome 仅申请该主机的访问权限；扩展 ID 本身不是认证，后续请求需要签名。

完成配置后首次引导自动隐藏，临时离线不会要求重新配置。高级设置中的“立即更新”用于上传待同步收藏并获取最新资料与阅读状态，不会导出到飞书。“断开当前资料库”仅用于更换连接：本机列表归档、服务端内容保留，不停止提醒或撤销配对；操作前会再次确认。

设置页提供可复制给自己 agent 的任务，同时把项目目录交给它。插件不会自动发消息。详见 [SETUP](SETUP.md) 和 [Agent 配置说明](SETUP.md#交给-agent-配置)。

## 收藏与阅读

打开 HTTP(S) 文章或视频，点击 ReadFlow，选填标签与笔记后收藏。只保存标题和链接，不抓取正文、不下载视频、不转写。同步成功的记录存入数据库。收藏页是默认首页，未读／已读／跳过三个筛选均显示数量。每行展示标题、来源、时间、标签和可展开笔记，可直接切换阅读状态；消息送达不代表已读，已关联条目的状态变更须成功写入服务后才确认。

飞书私聊入口与 Chrome 共用数据库并按链接去重。处理任务落库后，机器人确认新增／已存在的数量；不抓链接正文，也不开始 AI 对话。[飞书配置](docs/FEISHU-INBOX.md)。

## 按需导出

设置 → **导出资料库**：

- **下载 CSV**：先上传待同步收藏，再下载数据库中的全部记录，包含 UTF-8 编码和表格公式注入防护。服务错误会中止导出。无需飞书凭证；CSV 包含素材与笔记，但不是完整数据库备份。


## 可选阅读邀请

既有调度器调用 `daily`，设置页控制时间、时区和开关；页头语言同时用于提醒。调度和消息凭证保留在服务端，不自动安装调度任务。

开启飞书回调后，阅读卡片提供 **打开原文／已读／稍后（24小时）／跳过**。操作直接更新数据库，Chrome 下次同步可见。“稍后”推迟 24 小时再参与提醒，不标已读。每张交互卡片最多五条，剩余未读可能生成多张卡片；未配置回调时发送文字摘要。关闭提醒不停止链接收录，取消 Chrome 关联也不会停止服务端任务。

## 部署与边界

[自建指南](docs/SELF-HOSTING.md) · [架构](docs/ARCHITECTURE.md) · [接口约定](docs/CONNECTION.md) · [安全](SECURITY.md) · [MVP PRD](docs/MVP-PRD.md)

参考服务使用单机私有 SQLite 文件，不限定云平台、CLI 或 agent。备份时停止服务并备份整个私有状态目录。统一删除、Chrome 回顾列表、定时 AI 回顾、多机数据库集群尚未实现。Hermes 真实环境接入仍需验证。飞书测试使用模拟响应，真实部署仍需验证权限和回调。

当前仅维护标题、链接、阅读状态、收藏时间、标签、笔记、标记已读时间七项；不生成正文、分类或评分。笔记与原备注合并为一个输入，已有不同文字合并保留；数据库中已有的其他内容保留，但不再作为默认导出列。

## 对话型 agent 与消息渠道

AI 阅读讨论使用已有 agent 的对话入口，不限定消息平台；分析由用户已有的对话型 agent 完成。ReadFlow 不直接调用模型 API，不要求模型密钥，也不再同步多维表格。当前提供独立配对的 agent 查询、引用校验、确认后保存及回顾查询接口。Hermes 可通过 [接入指南](docs/AGENT.md) 中的签名工具完成配置；用户在已有对话中发起回顾并确认保存，不自动转发收藏或启动分析。真实 Hermes 环境仍需联调，Chrome 回顾列表与定时 AI 回顾尚未实现。消息送达不代表分析已执行，详见 [PRD](docs/MVP-PRD.md)。
