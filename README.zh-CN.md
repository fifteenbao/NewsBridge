# NewsBridge

**NewsBridge 在 [zarazhangrui/reading-block-lark](https://github.com/zarazhangrui/reading-block-lark/tree/main) 开源项目基础上修改。感谢原作者及贡献者，保留原项目的 [MIT 许可证](LICENSE)。**

[English](README.md) | [简体中文](README.zh-CN.md)

**收藏值得花时间理解的内容，用飞书整理与回顾。**

NewsBridge 是一个开源 Chrome 插件，帮助用户收藏文章、视频等需要投入时间理解的内容，并利用飞书多维表格管理素材、阅读状态、类别和笔记。

收藏 → 整理 → 阅读或观看 → 记录理解 → 回顾相关素材。

## 安装

需要 **Google Chrome 106 或以上版本**。NewsBridge 通过“加载已解压的扩展程序”安装；无需先配置飞书，就能体验本地收藏。

### 连接设置

首次安装会自动打开设置页；之后可**右键 NewsBridge 图标 → Settings**。粘贴**飞书多维表格链接**（含 `/base/…?table=tbl…` 的直接链接）和连接专用密钥，选择 **Save settings / Check connection**。页面会校验目标表格、预检八个字段并显示具体错误。链接只用于定位表格，不代表已授权；同步仍需连接版本安装包与宿主授权。离线版本仅在本机保存链接，不会访问飞书。已有收藏不会因粘贴另一张表的链接而自动切换目标。参见 [启动顺序与可运行参考](SETUP.md#runnable-reference-and-startup-order--可运行参考与启动顺序)。

### 下载插件或源码

选择下面任意一种方式：

| 下载内容 | 操作方式 | 在 Chrome 中选择的文件夹 |
| --- | --- | --- |
| 本仓库 Releases → Assets 中的 `newsbridge.zip`（如已提供） | 下载并解压 | 解压后直接包含 `manifest.json` 的文件夹 |
| 本仓库 **Code → Download ZIP** 下载的源码 | 下载并解压，无需构建 | 同时包含 `manifest.json`、`src/` 和 `icons/` 的源码根目录 |
| 已有本地源码 | 直接加载源码根目录，或按下方步骤生成精简安装包 | 源码根目录，或打包后的 `dist/newsbridge/` |

如果暂时没有发布安装包，使用 **Code → Download ZIP** 即可。请下载当前 NewsBridge 仓库；开头致谢链接中的原作者项目是另一个扩展。

### 在 Chrome 中加载

1. 将解压后的文件夹放到电脑上的固定位置。安装后仍需保留，Chrome 会继续读取其中的文件。
2. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择直接包含 `manifest.json` 的文件夹。选择文件夹，不要选择 ZIP 或单独的 manifest 文件。
5. 确认扩展列表出现 **NewsBridge**，并处于启用状态。
6. 点击 Chrome 工具栏的拼图形 **扩展程序** 按钮，将 **NewsBridge** 固定到工具栏。

使用插件安装包时，所选目录应类似：

```text
<选择这个文件夹>/
├── manifest.json
├── src/
├── icons/
└── LICENSE
```

### 第一次收藏

打开一个普通的 `https://` 文章或视频页面，点击 NewsBridge 图标。图标出现绿色 `✓` 表示收藏成功；点击会直接收藏，不打开弹窗。`!` 表示页面不支持或收藏/同步出错，悬停图标可查看详情；同步失败不会丢弃已成功保存的本地收藏。随后右键图标，选择 **Reading list**，即可看到已保存的标题和链接。`chrome://extensions` 等浏览器内部页面不能收藏。

默认安装包支持本地收藏，**没有域名访问权限，不需要连接密钥或后台服务**。飞书同步和每日提醒需要另行配置连接，详见 [配置指南](SETUP.md)，也可以把 [Agent 配置说明](docs/AGENT-SETUP.md) 交给你的 Agent。收藏视频保存的是页面标题和链接，不包含视频文件或转写内容。

### 从源码生成安装包（可选）

安装 Node.js 22+ 和 npm 后，在包含 `package.json` 的项目根目录打开终端，执行：

```sh
npm run build
```

会生成可直接加载的 `dist/newsbridge/` 文件夹，以及 `dist/newsbridge.zip` 压缩包。无需执行 `npm install`。Node.js 仅用于打包和开发，日常使用插件不需要。

### 安装遇到问题

- **提示“清单文件缺失或无法读取”：** 检查是否已解压，并选择直接包含 `manifest.json` 的目录，不要选它的上一级目录。
- **工具栏找不到图标：** 打开 Chrome 的扩展程序菜单，固定 NewsBridge。
- **收藏没有出现在飞书：** 本地安装不会自动开启同步，请完成上方链接中的连接配置。
- **更新插件：** 将新文件放回原安装目录，然后在 `chrome://extensions` 的 NewsBridge 卡片上点击“重新加载”。保留原目录和 Chrome 配置；卸载扩展可能清除本地收藏。

## 使用已有工具连接飞书

飞书同步是可选能力。NewsBridge 定义连接接口，不要求使用指定命令行工具、云服务商、服务器系统或 Agent 产品。

Agent 可以检查用户已有环境，利用已授权的飞书连接实现接口，并为其 HTTPS 连接地址生成私人安装包，地址可包含应用子路径。能发飞书消息，不代表能读写多维表格；这些能力需要分别验证。

- [配置指南](SETUP.md)：安装与环境检查。
- [连接接口](docs/CONNECTION.md)：适配操作、鉴权与调度约定。
- [Agent 配置说明](docs/AGENT-SETUP.md)：允许配置的范围及验证步骤。

当前浏览器通过经过鉴权的 HTTPS 接口通信。已有工具需要直接或通过适配器提供此接口。仓库提供可嵌入的连接模块与可运行的飞书自建应用适配器，不预设任何第三方产品已经兼容。已有环境能提供接口时，不必另外部署托管服务。

## 多维表格

请保留以下准确的字段名称。

| 标题 | 链接 | 内容 | 类别 | 阅读状态 | 推荐指数 | 笔记 | 时间 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 文本主字段 | 超链接或文本 | 摘要与回顾问题 | 单选或多选 | 单选 | 数字或评分，1–5 | 个人理解 | 收藏日期 |

阅读状态：**待阅读、阅读中、已读、已沉淀、归档**。只有前两项视为未读。对视频，同一字段表示手动更新的观看进度，不会自动追踪播放。

新收藏保存标题与链接，类别为待分类。已有内容、笔记和状态以飞书为准。收藏后、浏览器启动时、手动操作时同步；启用同步后，Chrome 运行期间每 15 分钟同步。飞书的修改在下一次同步时显示。关联记录只有在远端状态更新成功后才更新本地状态。在飞书中删除关联记录后，同步不会重新创建它。

## 可选的每日提醒

用户已有的调度工具可以在 **Asia/Shanghai 每天上午 10 点**触发连接模块，时区可配置。配置会话并验证发消息权限、持久化发送记录及共享锁后，再启用提醒。

每次发送前重新读取多维表格，排除已读或已删除素材，每条消息最多包含 20 条链接。不再使用满 5 条的门槛。发送不会标为已读；当天完成后不重复，之后新增的素材等到明天，仍未读的素材可次日再次提醒。延迟运行时只补当天 10 点后的提醒。

Chrome 不自行发送定时提醒；发送依赖所选调度工具和连接持续可用。发送结果不确定、超过重试窗口或内容/状态变化时会暂停；先核对飞书会话，再在 Settings 中确认结果。

## 开发与隐私

```sh
npm run doctor
npm test
npm run security
npm run build
```

无 npm 运行时依赖。连接模块由宿主环境提供适配器、持久化存储和锁，不会启动监听服务或调度器。公开扩展包只包含清单、浏览器代码、图标和许可证。真实域名和凭证只放在私人配置及私人安装包中，不进入公开发布包。

详见 [安全边界](SECURITY.md)、[架构说明](docs/ARCHITECTURE.md) 和 [相关项目](docs/RELATED-PROJECTS.md)。测试使用模拟飞书操作，不能证明未经验证的第三方工具或部署环境已经兼容。
